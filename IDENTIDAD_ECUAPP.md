# Identidad corporativa de EcuApp

Plataforma de marca propuesta para el sitio institucional y las comunicaciones comerciales.

## Esencia

**EcuApp convierte necesidades operativas en tecnología que encaja con la empresa.** Diseña software, interfaces, APIs e integraciones que pueden convivir con los sistemas que una organización ya utiliza.

EcuApp es una empresa ecuatoriana de ingeniería de software. Combina servicios de desarrollo e integración para organizaciones con un portafolio propio de productos digitales. El trabajo puede tomar la forma que requiera cada proyecto: una interfaz para personas, una API B2B para conectar sistemas, un servidor MCP para exponer capacidades a herramientas y agentes autorizados, o una combinación de esas piezas.

## Propósito

Hacer que la tecnología responda a la operación real de cada organización.

## Misión

Diseñar y desarrollar soluciones digitales útiles, seguras e interoperables que ayuden a las organizaciones a resolver sus retos operativos, conectar sus sistemas y evolucionar con una base tecnológica mantenible.

## Visión

Ser un socio tecnológico de confianza para organizaciones de Ecuador y la región, reconocido por adaptar la ingeniería a cada contexto y por construir ecosistemas digitales que puedan crecer sin perder control ni continuidad.

## Posicionamiento

**EcuApp es el socio de ingeniería que se adapta a la empresa:** entiende cómo trabaja, conecta la tecnología existente y construye lo que falta, desde una interfaz de usuario hasta una integración B2B o una experiencia basada en MCP.

### Audiencias principales

- Empresas que necesitan automatizar procesos o desarrollar software propio.
- Equipos que deben conectar ERP, CRM, sistemas internos, bases de datos y servicios de terceros.
- Organizaciones que necesitan ofrecer o consumir capacidades mediante APIs B2B o integraciones con agentes.
- Equipos que requieren una interfaz propia, modernización o evolución de un producto digital.

## Promesa de marca

**Nos adaptamos a tu operación. Conectamos lo que ya funciona. Construimos lo que hace falta.**

### Descriptor

Ingeniería de software e integración empresarial.

### Frase institucional

Tecnología hecha para encajar con tu empresa.

## Propuesta de valor

EcuApp empieza por el proceso y el entorno tecnológico de cada cliente, no por una plantilla. A partir de ese contexto propone una arquitectura y un alcance que pueden combinar desarrollo a medida, productos propios e integración con otros sistemas.

### Capacidades que expresan la promesa

1. **Software a medida:** aplicaciones web y sistemas internos según reglas de negocio.
2. **APIs B2B:** contratos e integraciones de sistema a sistema definidos para el caso de uso.
3. **MCP e IA aplicada:** conexión de capacidades empresariales con herramientas o agentes bajo permisos y alcance acordados.
4. **Integración y modernización:** adaptación a plataformas y sistemas existentes, con evolución gradual.
5. **Interfaces propias:** portales y paneles para los equipos que operan el negocio.
6. **Productos EcuApp:** soluciones propias que se desarrollan y validan por etapas.

Estas capacidades describen lo que EcuApp puede diseñar y construir como servicio. No implican que cada API, producto o integración esté hoy desplegado o disponible para contratación inmediata.

## Principios y valores

- **Ajuste al contexto:** entender primero los flujos, restricciones y objetivos de la empresa.
- **Interoperabilidad:** permitir que los sistemas compartan información con contratos explícitos y límites claros.
- **Seguridad y privacidad desde el diseño:** definir permisos, acceso y tratamiento de datos como parte de la solución.
- **Claridad y honestidad:** diferenciar una idea, un prototipo, una validación y un servicio en producción.
- **Ingeniería sostenible:** favorecer soluciones legibles, mantenibles y ampliables.
- **Colaboración responsable:** acordar alcance, responsabilidades y siguientes pasos con cada cliente.

## Personalidad y voz

EcuApp se expresa como un equipo de ingeniería cercano, claro, riguroso y práctico. Explica los conceptos técnicos con lenguaje sencillo, evita vender resultados no medidos y habla de decisiones, límites y etapas con transparencia.

### Sí decir

- “Diseñamos la integración alrededor de tus sistemas y procesos.”
- “Podemos trabajar con tu arquitectura actual o construir la interfaz que necesitas.”
- “Definimos el alcance, los permisos y el entorno antes de conectar los sistemas.”
- “Cada producto muestra su etapa documentada.”

### Evitar

- Presentar APIs, MCP o productos en desarrollo como endpoints o servicios activos.
- Afirmar compatibilidad universal, resultados, ahorros, seguridad certificada, uptime o SLA sin evidencia y acuerdo.
- Confundir el portafolio propio con la totalidad de los servicios de EcuApp.

## Identidad visual recomendada

- **Activo oficial:** usar el emblema de montaña disponible en [EcuApp/hefesto](https://github.com/EcuApp/hefesto/blob/main/app-hefesto-ecuapp/src/assets/ecuapp-logo.png). Conservar sus proporciones, colores y fondo; no redibujarlo como una montaña azul genérica.
- **Paleta derivada del logo:** azul marino `#001749`, azul petróleo `#4D7285`, amarillo sol `#FFEB00`, naranja `#FF8C00` y rojo `#FF0B33`. El marfil y los grises cálidos dan aire al contenido; el petróleo, el marino y el amarillo llevan el peso de la identidad.
- **Uso del color:** reservar amarillo para foco, progreso y acciones principales; naranja para énfasis y rutas; rojo para acentos puntuales. Evitar que cian y azul eléctrico dominen la página.
- **Composición:** mezclar paneles limpios con escenas de producto reales, diagramas de rutas, capas y profundidad. Las pantallas reales deben indicar a qué producto pertenecen y si son vistas de desarrollo.
- **Movimiento:** animar para explicar conexiones y cambios de estado. Usar scroll storytelling acotado, capas 2.5D y transiciones suaves; nunca bloquear el scroll ni esconder contenido. Mantener un diseño completo sin animación y respetar `prefers-reduced-motion`.
- **Iconografía:** familia lineal de trazos consistentes, con SVG accesible y color tomado del contexto. Evitar depender de caracteres Unicode como sustituto de iconos.

## Arquitectura de marca

- **EcuApp:** empresa, ingeniería de software e integración.
- **Servicios EcuApp:** proyectos a medida, integración, APIs B2B, MCP, interfaces y modernización.
- **Productos EcuApp:** portafolio de iniciativas propias, cada una con identidad, alcance y madurez documentada.

## Mensajes clave para el sitio

1. EcuApp construye software a medida para otras organizaciones.
2. Puede integrarse con la tecnología existente de cada empresa.
3. Una solución puede exponer capacidades mediante una interfaz, API B2B o MCP según el caso.
4. Los productos propios son una parte del ecosistema, no la única oferta de EcuApp.
5. La etapa de madurez de cada iniciativa se comunica con precisión.
